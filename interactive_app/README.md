# WMR 传感器攻击仿真 — 交互式浏览器

## 简介

本工具为 WMR（轮式移动机器人）传感器攻击检测研究提供交互式仿真环境。您可以通过图形界面自由选择轨迹、攻击类型和参数，运行闭环仿真后通过时间滑块回放机器人在任意时刻的状态。

## 功能

- **双模式轨迹选择**：
  - *数据集模式*：从已有 60 条配置中选取（来自 `dataset/metadata.csv`）
  - *自定义模式*：手动指定 5 族轨迹的参数
- **9 种攻击类型**（A0 正常 ~ A8 传感器冻结），可调起始时间和持续时间
- **后台仿真**：NMPC+IPOPT 闭环仿真，约 1000 步 / 20 秒
- **6 面板可视化**：
  1. 2D 轨迹（参考路径 + 真实路径 + 攻击段高亮）
  2. 跟踪误差 (x_e, y_e, θ_e)
  3. 控制指令 (v_cmd, ω_cmd)
  4. EKF 新息
  5. 攻击信号
  6. 测量值 vs 真值 vs EKF 估计（可选 X/Y/θ 通道）
- **时间滑块回放**：拖动滑块实时查看任意时刻的机器人状态
- **自动播放**：Space 键启动/暂停，可调播放速度

## 环境要求

- Conda 环境：`D:\anaconda\envs\learning&control`

## 操作说明

### 参数设置
1. 选择轨迹来源（数据集记录 / 自定义参数）
2. 选择具体轨迹配置或手动设置参数
3. 选择攻击类型、起始时间和持续时间
4. 按 **F5** 或点击「运行仿真」按钮

### 回放控制
| 操作 | 快捷键 |
|------|--------|
| 拖动时间滑块 | 鼠标拖拽 |
| 逐帧前进/后退 | ← → |
| 快速跳转 50 帧 | Ctrl + ←/→ |
| 跳到开头/结尾 | Home / End |
| 播放/暂停 | Space |
| 切换测量对比通道 | 界面底部单选按钮 |

### 可视化面板
- **工具栏**（底部）：缩放、平移、保存图片
- **测量对比通道**（底部）：切换 X/Y/θ 通道的测量值/真值/估计值对比

## 注意事项

- 仿真运行期间界面可能略有卡顿（NMPC 求解占用 CPU）
- 首次运行需加载 CasADi 求解器（约 0.5 秒）
- A0（正常）模式下攻击起始时间自动设为仿真时长之外
- 数据集模式下，轨迹参数与原始数据完全一致（使用相同的 deterministic seed）
