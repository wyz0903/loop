# 恢复方案综合对比

> 本目录包含 3 套"检测→恢复→闭环跟踪"方案，均通过子智能体可行性审查并修复阻断性问题。

## 方案一览

| 维度 | 方案 A：物理引导解码器 | 方案 B：自适应观测器 | 方案 C：可微 NMPC 闭环训练 |
|------|----------------------|---------------------|--------------------------|
| **核心机制** | `ŷ = y_kin + δ(features, class_emb)` | EKF 预测-修正，R 由类别先验调度 | 同 A + 跟踪误差 loss 闭环微调 |
| **路线** | 数据驱动 | 控制论白盒 | 数据驱动 + 控制论 |
| **导师接受度** | 中（δ 用脏测量，信息丢失退化到 y_kin） | **高**（标准闭环滤波器，K→0 是自适应降权） | 中高（同 A + 闭环训练创新性） |
| **创新性** | 低（已有解码器 + class emb） | 中（类别条件 R 调度） | **高**（可微 NMPC + 条件先验 + 物理引导） |
| **工程量** | **1-2 天** | ~1 天 | 2-3 周（修复后） |
| **闭环分布偏移** | ❌ 未解决 | ✅ 不涉及（白盒，无训练分布） | ✅ 解决（闭环训练） |
| **信息保留攻击 (A1/A2/A3/A6)** | ✅ 可恢复 | ✅ 可恢复 | ✅ 可恢复（最优） |
| **信息丢失攻击 (A4/A5/A7)** | ⚠️ 退化到 y_kin（弱开环） | ⚠️ K→0 退化到预测（滤波器自适应） | ⚠️ δ→0 退化到 y_kin（loss 逼出） |
| **需 GPU 训练** | 是 | **否** | 是 |
| **需新增依赖** | 无 | 无 | 无（CasADi 已有） |
| **前置依赖** | 无 | 无 | **方案 A 必须先完成** |

## 推荐执行顺序

```
方案 B（1天，快速验证闭环可辩护性）
  ↓ 若导师接受 EKF 路线
方案 A（1-2天，数据驱动恢复，与 B 对比）
  ↓ 若需要创新性
方案 C 简化版（跟踪误差监督，无可微 NMPC，1天）
  ↓ 若简化版有效
方案 C 完整版（可微 NMPC，2-3周）
```

**理由**：
1. **方案 B 先做**：工程量最小（~1天），不依赖 GPU 训练，导师最易接受（标准 EKF 框架）。快速验证"闭环可辩护的恢复"是否可行。若 R 调度表数值合理 + 闭环收敛，路线立住。
2. **方案 A 跟进**：与 B 对比"数据驱动 vs 白盒"的恢复质量差异。若 A 显著优于 B，说明数据驱动修正有价值。
3. **方案 C 简化版**：去掉可微 NMPC，直接用跟踪误差 loss 微调方案 A 的 decoder。验证"对齐跟踪目标"是否改善闭环收敛。这是方案 C 的核心价值（不是可微 NMPC 本身）。
4. **方案 C 完整版**：仅在简化版有效且需要论文创新性时投入。可微 NMPC 工程量大、梯度链断裂风险高，ROI 需评估。

## 关键风险

| 风险 | 影响方案 | 缓解 |
|------|---------|------|
| 信息丢失攻击期无解（信息论硬限制） | 全部 | 论文明确为已知局限，攻击后收敛即可 |
| 固定参数攻击→泛化性未验证 | A, C | 全流程跑通后参数随机化（用户已同意推迟） |
| 分类错误→恢复恶化 | A, B | 置信度门控（A: 阈值；B: R 插值） |
| 闭环分布偏移 | A | 方案 C 简化版（跟踪误差监督）或接受 |
| 可微 NMPC 梯度链断裂 | C | 简化版（跟踪误差监督，无 NMPC 梯度） |
