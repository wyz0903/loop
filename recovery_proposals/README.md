# 恢复方案综合对比

> 本目录包含 3 套"检测→恢复→闭环跟踪"方案。

## 方案一览

| 维度 | 方案 A：物理引导解码器 | 方案 B：自适应观测器 | 方案 C：跟踪误差监督闭环训练 |
|------|----------------------|---------------------|--------------------------|
| **核心机制** | `ŷ = y_kin + δ(features, class_emb)` | EKF 预测-修正，R 由类别先验调度 | 同 A + 跟踪误差 loss 闭环微调 |
| **路线** | 数据驱动 | 控制论白盒 | 数据驱动 + 控制论 |
| **导师接受度** | 中（δ 用脏测量，信息丢失退化到 y_kin） | **高**（标准闭环滤波器，K→0 是自适应降权） | 中高（同 A + 闭环训练创新性） |
| **创新性** | 低（已有解码器 + class emb） | 中（类别条件 R 调度） | **高**（跟踪误差监督 + 条件先验 + 物理引导） |
| **闭环分布偏移** | ❌ 未解决 | ✅ 不涉及（白盒，无训练分布） | ✅ 解决（闭环训练） |
| **信息保留攻击 (A1/A2/A3/A6)** | ✅ 可恢复 | ✅ 可恢复 | ✅ 可恢复（最优） |
| **信息丢失攻击 (A4/A5/A7)** | ⚠️ 退化到 y_kin（弱开环） | ⚠️ K→0 退化到预测（滤波器自适应） | ⚠️ δ→0 退化到 y_kin（loss 逼出） |
| **需 GPU 训练** | 是 | **否** | 是 |
| **前置依赖** | 无 | 无 | **方案 A 必须先完成** |

## 推荐执行顺序

```
方案 B → 方案 A → 方案 C
```

**理由**（基于科研价值与可行性）：
1. **方案 B 先做**：控制论白盒，导师最易接受（标准 EKF 框架，K→0 是自适应降权而非开环）。快速验证"闭环可辩护的恢复"是否可行，为后续方案提供 baseline。
2. **方案 A 跟进**：数据驱动恢复，与 B 对比"学习修正 vs 白盒滤波"的恢复质量差异。验证类别条件 embedding 是否让 δ 自动分化两类攻击行为。
3. **方案 C 最后**：在方案 A 基础上用跟踪误差 loss 闭环微调，解决分布偏移、对齐跟踪目标。这是创新性最强、科研价值最高的路线，但依赖方案 A 的架构。

## 关键风险

| 风险 | 影响方案 | 缓解 |
|------|---------|------|
| 信息丢失攻击期无解（信息论硬限制） | 全部 | 论文明确为已知局限，攻击后收敛即可 |
| 固定参数攻击→泛化性未验证 | A, C | 全流程跑通后参数随机化 |
| 分类错误→恢复恶化 | A, B | 置信度门控（A: 阈值；B: R 插值） |
| 闭环分布偏移 | A | 方案 C（跟踪误差监督）或接受 |
